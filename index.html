เริ่มจากเมนูด้านล่าง LINE ช่าง

Rich Menu ของบอท SitePulse
4

ลงทะเบียนผ่าน LINE ช่างทำ

กด Register หรือพิมพ์ “ลงทะเบียน”
  1. พิมพ์ ชื่อ–นามสกุล
  2. พิมพ์ Email
  3. พิมพ์ เบอร์โทร 10 หลัก (หรือ - เพื่อข้าม)
  4. ได้การ์ด ลงทะเบียนสำเร็จ — รอ Admin อนุมัติ
5

อนุมัติช่าง + ผูกบริษัท ของ Admin · ช่างรออย่างเดียว

เมื่ออนุมัติแล้ว กด “เปิดเมนู” หรือพิมพ์ เมนู
ช่างไม่ต้องทำอะไรในเว็บ — รอการ์ด ✅ อนุมัติแล้ว แล้วเริ่ม Check-In ได้
6

Check-In ช่างทำ

อยู่ในรัศมีไซต์ ≤ 100 ม. · เปิด GPS · อนุญาตตำแหน่ง

A เลือกงาน → เปิดหน้า Check-In

  1. กด Check-In จากเมนู
  2. เลือกการ์ดงาน (เช่น สำรวจหน้างาน TSS)
  3. กด เปิด Check-In (ลิงก์ใช้ได้ 1 ชม.)

B อนุญาตตำแหน่ง + ได้ GPS

ต้องกด Allow เมื่อระบบขอใช้ตำแหน่ง — ไม่กดจะ Check-In ไม่ได้

C เลือก % + ถ่ายรูปหน้างาน

แนะนำถ่าย (อย่างน้อย 1 รูป) หน้าไซต์ · เครื่องมือ · เครื่องจักร/อุปกรณ์ · ชุด PPE

D ในรัศมี ✓ / นอก ✗

✓ ในรัศมี ≤ 100 ม. → Check-In สำเร็จ · Geofence แสดง “ผ่าน”
✗ นอกรัศมี → ไม่ผ่าน · ระบบบอกระยะห่าง · เดินเข้าใกล้แล้วลองใหม่

! ลิงก์หมดอายุ

ลิงก์ Check-In / Out ใช้ได้ 1 ชั่วโมง ถ้าหมดอายุ → กลับแชท · พิมพ์ เมนู หรือกด Check-In ใหม่ · เปิดลิงก์ใหม่ภายใน 1 ชม.
7

แจ้งเตือนกลุ่ม + อัปเดต % ของระบบ/บอท · ช่างไม่กดอะไร

บอทโพสต์ในกลุ่ม LINE ของไซต์
ช่างไม่ต้องกดอะไรเพิ่ม — ดูในกลุ่มว่ามี ✅ Check-In · 🔔 งานครบแล้ว · 🔚 Check-Out
8

Check-Out ช่างทำ · จบงานช่างที่นี่

เลิกงาน / จบช่วงงาน — ระบบคำนวณชั่วโมง
  1. กด Check-Out / พิมพ์ ออกงาน → กด เปิด Check-Out
  2. ยืนยันว่าเป็นงานที่ Check-In อยู่ + ดึง GPS
  3. เลือก % ความคืบหน้าจริง
  4. แนบรูป/เอกสารได้ (ไม่บังคับ ยกเว้นปิดงาน 100%)
  5. กด ยืนยัน Check-Out (ปุ่มแดง)
มี Check-In ค้าง ต้อง Check-Out ก่อนจึงจะ Check-In งานใหม่ได้
✓ งานของช่างจบที่ขั้น 8 (Check-Out สำเร็จ) หลังจากนี้ช่างไม่ต้องเข้าเว็บ · ยกเว้นได้รับ “RPM ส่งคืนงาน” ถึงค่อย Check-In ใหม่แก้ตามเหตุผล
ด้านล่างนี้ = คนอื่นทำ (ช่างอ่านเพื่อเข้าใจภาพรวมเท่านั้น)
9

Verify — อนุมัติ / ส่งคืน ของ RPM · ไม่ใช่ช่าง

RPM ตรวจบนเว็บ SitePulse → อนุมัติ หรือ ส่งคืน
เจ้าของขั้น: RPM (เว็บ)
ช่างไม่เข้าหน้า Verify · ถ้าถูกส่งคืน จะได้รับการ์ดแดงใน LINE → Check-In ใหม่เพื่อแก้ แล้วส่ง Verify อีกครั้ง
10

ดู Dashboard / รายงาน ของ CBM / ผู้บริหาร · ไม่ใช่ช่าง

ดู Exclusive Summary / Gantt / ความคืบหน้าบนเว็บ
เจ้าของขั้น: CBM / ผู้บริหาร (ทีมที่ดูระบบได้)
ช่างไม่ต้องเข้าเว็บรายงาน — ข้อมูลมาจาก Check-In/Out ที่ทำไปแล้ว
