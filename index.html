เริ่มจากเมนูด้านล่าง LINE ช่าง

Rich Menu ของบอท SitePulse
4

ลงทะเบียนผ่าน LINE ช่างทำ

กด Register หรือพิมพ์ “ลงทะเบียน”
  1. พิมพ์ ชื่อ–นามสกุล
  2. พิมพ์ Email
  3. พิมพ์ เบอร์โทร 10 หลัก (หรือ - เพื่อข้าม)
  4. เลือก ภูมิภาค / ML (กดปุ่ม 1–6 หรือพิมพ์เลข)
  5. ได้การ์ด ลงทะเบียนสำเร็จ — รอ Admin อนุมัติ
5

อนุมัติช่าง + ผูกบอทกลุ่ม ของ Admin · ช่างรออย่างเดียว

เมื่ออนุมัติแล้ว กด “เปิดเมนู” หรือพิมพ์ เมนู
ช่างไม่ต้องทำอะไรในเว็บ — รอการ์ด ✅ อนุมัติแล้ว แล้วเริ่ม Check-In ได้

A Admin อนุมัติช่างบนเว็บ

B Admin ดึงบอทเข้ากลุ่ม + ผูกไซต์ (สำหรับแจ้งกลุ่ม)

  1. เชิญ Bot SitePulse เข้ากลุ่ม LINE ของไซต์
  2. กด เปิดเมนูกลุ่ม → เพิ่มไซต์งาน
  3. พิมพ์รหัสผู้รับเหมา (เช่น CON-DEMO) → กดเพิ่มไซต์
6

Check-In ช่างทำ

อยู่ในรัศมีไซต์ ≤ 100 ม. · เปิด GPS · อนุญาตตำแหน่ง / กล้อง

A เลือกงาน → เปิดหน้า Check-In

  1. กด Check-In จากเมนู
  2. เลือกไซต์ → เลือกการ์ดงาน (เช่น สำรวจหน้างาน TSS)
  3. กด เปิด Check-In (ลิงก์ใช้ได้ 1 ชม.)

B แนะนำเปิดนอก LINE (GPS / กล้องเสถียรกว่า)

แนะนำเปิดในเบราว์เซอร์นอก LINE — กด “เปิดในเบราว์เซอร์” จะได้ GPS และกล้องที่เสถียรกว่า · หรือกด “ดำเนินการต่อใน LINE” ได้ถ้าจำเป็น

C ได้ตำแหน่ง + เลือก % + ถ่ายรูป

ต้องกด Allow เมื่อขอตำแหน่ง / กล้อง — แนะนำถ่ายอย่างน้อย 1 รูป (หน้าไซต์ · เครื่องมือ · เครื่องจักร · PPE)

D ในรัศมี ✓ / นอก ✗

✓ ในรัศมี ≤ 100 ม. → Check-In สำเร็จ · แสดงระยะห่าง + % เป้าหมาย
✗ นอกรัศมี → ไม่ผ่าน · ระบบบอกระยะห่าง · เดินเข้าใกล้แล้วลองใหม่

! ลิงก์หมดอายุ

ลิงก์ Check-In / Out ใช้ได้ 1 ชั่วโมง ถ้าหมดอายุ → กลับแชท · พิมพ์ เมนู หรือกด Check-In ใหม่ · เปิดลิงก์ใหม่ภายใน 1 ชม.
7

แจ้งเตือนกลุ่ม + อัปเดต % ของระบบ/บอท · ช่างไม่กดอะไร

บอทโพสต์ในกลุ่ม LINE ของไซต์ (หลัง Admin ผูกไซต์แล้ว)
ช่างไม่ต้องกดอะไรเพิ่ม — หลัง Check-Out 100% จะเห็นการ์ด งานครบแล้ว · รอ Inspector แล้ว RPM Verify
8

Check-Out ช่างทำ · จบงานช่างที่นี่

เลิกงาน / จบช่วงงาน — ระบบคำนวณชั่วโมง
  1. กด Check-Out / พิมพ์ ออกงาน → กด เปิด Check-Out
  2. ยืนยันว่าเป็นงานที่ Check-In อยู่ + ดึง GPS
  3. เลือก % ความคืบหน้าจริง
  4. แนบรูปหน้างานได้ (ไม่บังคับ) · ถ้าปิดงาน 100% ต้องแนบเอกสารครบ (เช่น แบบฟอร์ม TSS)
  5. กด ยืนยัน Check-Out (ปุ่มแดง)
มี Check-In ค้าง ต้อง Check-Out ก่อนจึงจะ Check-In งานใหม่ได้
✓ งานของช่างจบที่ขั้น 8 (Check-Out สำเร็จ) หลังจากนี้ช่างไม่ต้องเข้าเว็บ · ยกเว้นได้รับ “ส่งคืนงาน” ถึงค่อย Check-In ใหม่แก้ตามเหตุผล
ด้านล่างนี้ = คนอื่นทำ (ช่างอ่านเพื่อเข้าใจภาพรวมเท่านั้น)
9

Verify — Inspector → RPM ไม่ใช่ช่าง

Dual approve บนเว็บ · Inspector ขั้น 1 → RPM ขั้นสุดท้าย · ส่งคืนทำโดย Inspector (หรือ Admin)
เจ้าของขั้น: Inspector แล้วตามด้วย RPM (เว็บ)
ช่างไม่เข้าหน้า Verify · ถ้าถูกส่งคืน จะได้รับการ์ดใน LINE → Check-In ใหม่เพื่อแก้ แล้วส่ง Verify อีกครั้ง
เหตุผลส่งคืน: รูปไม่ถูก/ไม่ครบ หรือ ติดตั้งผิด
10

ดู Dashboard / รายงาน ของ CBM / ผู้บริหาร · ไม่ใช่ช่าง

ดู Exclusive Summary / Gantt / ความคืบหน้าบนเว็บ
เจ้าของขั้น: CBM / ผู้บริหาร (ทีมที่ดูระบบได้)
ช่างไม่ต้องเข้าเว็บรายงาน — ข้อมูลมาจาก Check-In/Out ที่ทำไปแล้ว
